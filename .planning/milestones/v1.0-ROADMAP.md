## Overview

PropManager MVP — property portfolio management platform for a family with 30+ properties in Ahmedabad. Replaces Excel sheets and paper records with a unified dashboard, AI-powered document processing, and comprehensive financial tracking. Deployed as an installable PWA on Vercel.

## Milestone Summary

**Key Decisions:**
- NextAuth v5 with credentials provider (switched from Stack Auth for simplicity)
- Neon serverless Postgres with Drizzle ORM HTTP adapter
- Base64 data URI storage in Postgres for documents (no external storage for v1)
- @serwist/next for PWA (modern fork of next-pwa)
- Next.js pinned to 15.x (16.x incompatible with serwist webpack plugin)
- Event-based Radix Toast for notifications (no state management library)

**Issues Resolved:**
- drizzle-kit .env.local loading (added dotenv)
- Next.js 15.1.3 CVE blocked by Vercel (updated to 15.5.12)
- TypeScript webworker lib for ServiceWorkerGlobalScope
- Document list API performance (excluded base64 from list responses)

**Issues Deferred:**
- None

**Technical Debt Incurred:**
- Push notifications not implemented (PWA manifest supports it)
- Offline data sync not implemented (service worker caches assets only)
- Google OAuth not configured (credentials auth only)
- No form validation beyond required fields
