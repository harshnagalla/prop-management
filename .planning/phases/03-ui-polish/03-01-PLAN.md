  <action>
    Wire up toast notifications on all 4 CRUD pages for every API operation:

    **For each page (properties, bills, income, documents):**

    1. Wrap all fetch calls in try/catch blocks
    2. On successful create: `toast.success("Property added")` (or bill/income/document)
    3. On successful edit: `toast.success("Property updated")`
    4. On successful delete: `toast.success("Property deleted")`
    5. On API error (non-2xx response): `toast.error("Failed to save property")` with the error message from response if available
    6. On network error (catch block): `toast.error("Network error. Please try again.")`
    7. On the initial data load fetch, show toast.error if the fetch fails (don't silently show empty state)

    **For documents page specifically:**
    8. On upload success: `toast.success("Document uploaded")`
    9. On file too large: `toast.error("File too large. Maximum 10MB.")`
    10. On upload failure: `toast.error("Upload failed")`

    Import `toast` from `@/lib/utils/toast` in each page. Keep changes minimal — just wrap existing fetch calls and add toast calls after success/failure.
  </action>
  <verify>npm run build passes. All pages import toast utility.</verify>
