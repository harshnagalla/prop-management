  <files>src/lib/db/schema.ts, src/app/api/properties/[id]/remarks/route.ts</files>
  <action>
1. **Add `propertyRemarks` table to schema.ts:**

After the `documents` table definition, add:

```typescript
export const propertyRemarks = pgTable("property_remarks", {
  id: uuid("id").defaultRandom().primaryKey(),
  propertyId: uuid("property_id")
    .references(() => properties.id, { onDelete: "cascade" })
    .notNull(),
  userId: text("user_id").notNull(),
  content: text("content").notNull(),
  createdAt: timestamp("created_at").defaultNow().notNull(),
});

export type PropertyRemark = typeof propertyRemarks.$inferSelect;
export type NewPropertyRemark = typeof propertyRemarks.$inferInsert;
```

2. **Push schema to database:**
```bash
npm run db:push
```

3. **Create API route at `src/app/api/properties/[id]/remarks/route.ts`:**

**GET** — List remarks for a property (newest first):
- Auth check via `auth.getSession()`
- Extract `id` from params (Promise-based in Next.js 16)
- Query: `db.select().from(propertyRemarks).where(and(eq(propertyRemarks.propertyId, id), eq(propertyRemarks.userId, userId))).orderBy(desc(propertyRemarks.createdAt))`
- Return JSON array

**POST** — Add a new remark:
- Auth check
- Extract `id` from params
- Read `{ content }` from body
- Validate: content must be non-empty string
- Verify property exists and belongs to user (query properties table)
- Insert: `db.insert(propertyRemarks).values({ propertyId: id, userId, content }).returning()`
- Return the created remark with 201 status

**DELETE** — Delete a remark (for the remark ID passed as query param):
- Auth check
- Read remarkId from searchParams: `req.nextUrl.searchParams.get("remarkId")`
- Delete where id = remarkId AND userId = userId
- Return `{ ok: true }`

Follow the exact same patterns as existing API routes (auth import from `@/lib/auth/server`, NextRequest/NextResponse, params as Promise).
