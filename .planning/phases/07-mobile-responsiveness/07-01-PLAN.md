  <action>
The dashboard (6-col table) and bills (7-col table) are completely unreadable on mobile. Implement a **responsive table strategy**: show table on md+ screens, show card view on mobile.

**Dashboard (src/app/(app)/page.tsx) — Property Performance table:**

Add a mobile card view that shows on small screens, hide the table on small screens:

1. Wrap existing table in `<div className="hidden md:block">` to hide on mobile
2. Add a mobile card list `<div className="md:hidden space-y-3">` that maps over the same data
3. Each mobile card should show:
   - Property name (bold, top)
   - Status badge (Badge component, same variant mapping as table)
   - Key stats in a 2-col grid: Monthly Rent, Yield, ROI, Occupancy
   - Use the Card component for each entry
4. Keep the same data source — just different presentation

**Bills page (src/app/(app)/bills/page.tsx) — Bills table:**

Same pattern:

1. Wrap existing table in `<div className="hidden md:block">`
2. Add mobile card list `<div className="md:hidden space-y-3">`
3. Each mobile card should show:
   - Property name + Category (top line)
   - Amount (prominent)
   - Vendor + Due date (secondary text)
   - Status badge (Paid/Unpaid)
   - Edit/Delete buttons in a row
   - Use Card component

**Income page (src/app/(app)/income/page.tsx) — Income entry rows:**

The income entries inside month groups can get cramped on mobile:

1. Find the flex layout for each income entry row
2. Change to `flex flex-col sm:flex-row` so entries stack vertically on mobile
3. On mobile: property name on top, amount + status + actions on second row
4. Ensure touch targets remain adequate (min 32px for icon buttons)

Do NOT change any data fetching, state, or business logic. Only add responsive presentation alternatives.
