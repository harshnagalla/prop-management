<task type="auto">
  <name>Task 1: Create chart data API endpoint</name>
  <files>src/app/api/dashboard/charts/route.ts</files>
  <action>
Create a new GET route at `/api/dashboard/charts` that returns aggregated data for 3 charts:

1. **Monthly income (last 12 months):**
- Query `rentalIncome` grouped by year/month, summing amount
- Generate last 12 months as labels (e.g., "Apr 2025", "May 2025", ..., "Mar 2026")
- Fill months with no data as 0
- Return: `{ monthlyIncome: [{ month: "Apr 2025", amount: 45000 }, ...] }`

SQL approach:
```sql
SELECT year, month, SUM(amount::numeric) as total
FROM rental_income
WHERE user_id = $1
GROUP BY year, month
ORDER BY year, month
```
Then merge with generated 12-month range, filling gaps with 0.

2. **Expense breakdown by category:**
- Query `bills` grouped by category, summing amount
- Return: `{ expenseByCategory: [{ category: "electricity", amount: 12000 }, ...] }`
- Only include categories that have bills (no zero entries)

SQL approach:
```sql
SELECT category, SUM(amount::numeric) as total
FROM bills
WHERE user_id = $1
GROUP BY category
ORDER BY total DESC
```

3. **Monthly expenses (last 12 months):**
- Query `bills` using `dueDate` (fallback to `createdAt` if dueDate null) grouped by month
- Same 12-month range as income chart, fill gaps with 0
- Return: `{ monthlyExpenses: [{ month: "Apr 2025", amount: 8000 }, ...] }`

SQL approach: Use COALESCE(due_date, created_at) for the date, then EXTRACT month/year, GROUP BY.

**Implementation notes:**
- Use `auth()` session check (same pattern as existing `/api/dashboard`)
- Use Drizzle `sql` template for aggregation queries
- Parse all numeric amounts with `parseFloat()` (Postgres returns strings for numeric columns)
- Generate the 12-month range in JS: loop from `new Date()` back 11 months, format as "MMM YYYY"
- Use short month names: Jan, Feb, Mar, etc.
