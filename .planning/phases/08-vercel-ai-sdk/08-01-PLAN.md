3. Rewrite src/lib/ai/gemini.ts:

   - Import `generateText` from `ai`
   - Import `createGoogleGenerativeAI` from `@ai-sdk/google`
   - Create google provider: `const google = createGoogleGenerativeAI({ apiKey: process.env.GOOGLE_AI_API_KEY || "" })`
   - Keep EXACT same function signatures:
     - `extractBillData(base64Image: string, mimeType: string)` → same return type
     - `extractSpreadsheetData(base64File: string, mimeType: string)` → same return type

   For each function, use `generateText`:
   ```typescript
   const { text } = await generateText({
     model: google("gemini-2.0-flash"),
     messages: [
       {
         role: "user",
         content: [
           {
             type: "file",
             data: base64Image,  // base64 string without data: prefix
             mimeType: mimeType,
           },
           {
             type: "text",
             text: `...same prompt as current...`,
           },
         ],
       },
     ],
   });
   ```

   - Parse the response text the same way (strip markdown fences, JSON.parse)
   - Keep the same error handling (return {} or { properties: [] } on parse failure)

4. Do NOT modify src/app/api/ai/extract/route.ts — it imports the same functions with the same signatures, so it just works.

IMPORTANT: The Vercel AI SDK uses `type: "file"` with `data` (base64 string) and `mimeType` for inline file content. Do NOT use `type: "image"` — that's only for image URLs. Use `type: "file"` which handles both images and documents.
