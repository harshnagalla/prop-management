<task type="auto">
  <name>Task 1: Add bills/[id] and rental-income/[id] API routes</name>
  <files>src/app/api/bills/[id]/route.ts, src/app/api/rental-income/[id]/route.ts</files>
  <action>
    Create two new route files following the exact pattern from `src/app/api/properties/[id]/route.ts`:

    **bills/[id]/route.ts:**
    - GET: Fetch single bill by id, scoped to userId
    - PUT: Update bill fields, scoped to userId. Do NOT include updatedAt (bills table has no updatedAt column — unlike properties)
    - DELETE: Delete bill by id, scoped to userId

    **rental-income/[id]/route.ts:**
    - GET: Fetch single income record by id, scoped to userId
    - PUT: Update income fields, scoped to userId. No updatedAt column here either
    - DELETE: Delete income record by id, scoped to userId

    Both routes must use `params: Promise<{ id: string }>` (Next.js 15 async params pattern — see properties/[id] for reference). Always `and(eq(table.id, id), eq(table.userId, userId))` for multi-tenant isolation.
  </action>
  <verify>npm run build passes with no errors. New route files compile correctly.</verify>
  <done>Both /api/bills/[id] and /api/rental-income/[id] respond to GET, PUT, DELETE with proper auth and tenant scoping.</done>
</task>
