<task type="auto">
  <name>Task 1: Create per-property chart data API endpoint</name>
  <files>src/app/api/properties/[id]/charts/route.ts</files>
  <action>
Create a new GET route at `/api/properties/[id]/charts` that returns aggregated chart data for a single property. Follow the exact same pattern as the dashboard charts endpoint but scoped to one property.

1. **Auth check:** Same pattern as other API routes — `auth.getSession()`, check user.id

2. **Verify property ownership:** Query property by id AND userId to ensure the user owns it. Return 404 if not found.

3. **Monthly income (last 12 months):**
- Query `rentalIncome` WHERE propertyId = id, grouped by year/month, summing amount
- Generate 12-month range (same helper pattern as dashboard charts)
- Fill gaps with 0
- Return: `monthlyIncome: [{ month: "Apr 2025", amount: 25000 }, ...]`

4. **Monthly expenses (last 12 months):**
- Query `bills` WHERE propertyId = id, using COALESCE(dueDate, createdAt) for date, grouped by month
- Same 12-month range, fill gaps with 0
- Return: `monthlyExpenses: [{ month: "Apr 2025", amount: 8000 }, ...]`

5. **Expense breakdown by category:**
- Query `bills` WHERE propertyId = id, grouped by category, summing amount
- Only include categories with bills
- Return: `expenseByCategory: [{ category: "electricity", amount: 5000 }, ...]`

6. **Financial summary:**
- Total income received (all time)
- Total expenses (all time)
- Net income (income - expenses)
- Return: `summary: { totalIncome, totalExpenses, netIncome }`

**Implementation notes:**
- Copy the 12-month range generation logic from `src/app/api/dashboard/charts/route.ts`
- Use Drizzle `sql` template for aggregation queries
- Filter by both `propertyId` and `userId` for security
- Parse all numeric amounts with `parseFloat()`
  </action>

  <done>GET /api/properties/[id]/charts returns { monthlyIncome, monthlyExpenses, expenseByCategory, summary } filtered to single property. Auth-protected with ownership check.</done>
