Then apply the design decisions:

1. **Font**: Install Inter via `next/font/google` in layout.tsx. Apply as CSS variable `--font-sans` and use in body. Inter is the standard for clean minimal dashboards (Linear, Vercel, Notion all use it or similar).

2. **Color palette**: Update globals.css @theme block with a refined clean minimal palette. Keep dark theme as default but make tokens semantic. Target aesthetic: muted backgrounds, subtle borders, clear hierarchy through typography weight not color noise. Specific guidance:
   - Background should be true dark (#0a0a0b or similar), not gray-tinted
   - Card backgrounds slightly elevated (#111113 → refine if needed)
   - Muted text should have good contrast but feel secondary (#71717a range)
   - Primary: refined blue (keep #3b82f6 or shift slightly)
   - Accent: keep emerald green for financial positive indicators
   - Add semantic tokens: --color-success, --color-info for status indicators
   - Borders: very subtle (#1e1e22 range — less visible than current)

3. **Spacing scale**: Add spacing tokens if the ui-ux-pro-max skill recommends them. Otherwise rely on Tailwind defaults.

4. **Typography scale**: Add --font-heading variable if a different weight/tracking is recommended for headings vs body.

Do NOT change component files in this task — only globals.css and layout.tsx.

<task type="auto">
  <name>Task 2: Create reusable component primitives</name>
  <files>src/components/ui/button.tsx, src/components/ui/input.tsx, src/components/ui/card.tsx, src/components/ui/badge.tsx</files>
  <action>
Create four foundational component primitives using the new design tokens. Use class-variance-authority (cva) for variant management and cn() for class merging. These components will be used across all pages in Phase 6.

1. **Button** (src/components/ui/button.tsx):
   - Variants: default (primary fill), secondary (muted fill), outline (border only), ghost (no background), destructive (red)
   - Sizes: sm, default, lg, icon
   - Props: extends ButtonHTMLAttributes, adds variant, size, asChild (via Radix Slot)
   - Style: clean minimal — subtle rounded corners (use --radius), smooth transitions, focus-visible ring
   - Do NOT over-style — minimal shadows, no gradients

2. **Input** (src/components/ui/input.tsx):
   - Extends InputHTMLAttributes
   - Style: bg-transparent or very subtle bg, border-border, focus ring with primary color, placeholder in muted-foreground
   - Clean and simple — no floating labels, no icons built-in (those are composition patterns)

3. **Card** (src/components/ui/card.tsx):
   - Exports: Card, CardHeader, CardTitle, CardDescription, CardContent, CardFooter
   - Style: bg-card, border-border, rounded with --radius, subtle shadow or none (clean minimal)
   - Composable — each sub-component is a simple styled div

4. **Badge** (src/components/ui/badge.tsx):
   - Variants: default (primary), secondary (muted), success (green), warning (amber), destructive (red), outline
   - Style: small inline pill, subtle color fills not loud, clean type

All components must:
- Use forwardRef for ref forwarding
- Use cn() from @/lib/utils/cn for class merging
- Accept className prop for overrides
- Use the design tokens from globals.css (not hardcoded colors)
- Be TypeScript with proper types exported
